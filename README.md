# Clasificación y Aplicaciones de los dispositivos móviles

Presentación interactiva (HTML, CSS y JavaScript sin dependencias) con una dinámica final por equipos de 5 preguntas y cronómetro de 90 segundos.

## Publicación en GitHub Pages

El sitio es estático y no requiere compilación:

1. En **Settings → Pages**, elige **Deploy from a branch**.
2. Selecciona la rama `main` y la carpeta `/ (root)`.
3. Guarda los cambios y abre la URL publicada.

`index.html` carga `static/core.css` y `static/index.js` con rutas relativas, por lo que funciona tanto en la raíz del dominio como en una ruta de proyecto (`usuario.github.io/repositorio/`). El archivo `.nojekyll` evita el procesamiento de Jekyll.

La hoja de respuestas para el equipo expositor está en `respuestas-quiz.md`.
